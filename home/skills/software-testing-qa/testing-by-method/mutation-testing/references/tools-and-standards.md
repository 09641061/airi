## Universal Mutation Testing Frameworks

- [Stryker Mutator](https://stryker-mutator.io/) - Multi-language mutation framework for JavaScript/TypeScript, C# (.NET), and Scala.
- [PITest](https://pitest.org/) - Industry standard mutation testing system for Java & JVM languages.
- [Mutmut](https://github.com/boxed/mutmut) - Python mutation testing system.
- [Cargo-mutants](https://github.com/sourcefrog/cargo-mutants) - Mutation testing for Rust projects.

Pick the framework matching the project's stack; all of them implement the same core operators and Killed/Survived/Timed Out/Equivalent taxonomy described in [execution-and-classification.md](execution-and-classification.md).
